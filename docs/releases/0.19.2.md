# AgenC 0.19.2

AgenC 0.19.2 fixes problems found while testing 0.19.1 on clean installs.

## Fixes

- On macOS, `agenc daemon restart` no longer leaves launchd restarting the
  daemon every few seconds. The installer and `brew services` run the daemon
  as a launchd job that restarts it whenever it exits. The restart command
  used to start its own copy, so the job's copy refused to run and exited,
  and launchd started it again, without end. Every start from the CLI or the
  TUI now goes through the launchd job when one runs that AgenC home.
- Starting AgenC in your home folder no longer says that trusting it turns on
  settings "this repo ships". Those were your own settings in
  `~/.agenc/config.toml`, which apply everywhere and need no trust.

## Upgrade notes

Standalone installations update with `agenc update`; npm installations with
`npm install -g @tetsuo-ai/agenc@0.19.2`. Then run `agenc daemon restart`.
On a Mac that ran `agenc daemon restart` on 0.19.1, this restart also ends
the launchd loop and hands the daemon back to launchd.
